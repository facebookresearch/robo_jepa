# 1X EVE humanoid (`1x_robot`)

1X EVE is a wheeled humanoid. The data is the public 1X world-model release (`1x-technologies/world_model_raw_data`,
`train_v2.0_raw`): each episode is one segment of `states_<shard>.bin` (float32 [N, 25], 30 Hz), and the episode
path `episodes_<shard>/episode<segment>` names the public shard and segment.

## Dataset

| Config entry | Embodiment (id) | Data (`s3_prefix`) | Raw → WM rate | Time per WM step | Cameras → view id | Weight |
|---|---|---|---|---|---|---|
| `1X` | `1x_robot` (20) | `1x-data` | 30 → 3 Hz | 0.33 s (10 frames) | `front` 3 (one view, 512×512) | 0.0017 (1-view only) |

## WM input

| Embodiment (id) | Source | State (dim) | Action per WM step (dim) |
|---|---|---|---|
| `1x_robot` (20) | state-delta | `cartesian_position[25]` = 25 (`gripper_dim: 0`) | element-wise `state[t+1] − state[t]` = 25 |

The 25-D state (public index table):

| Idx | Content | Notes |
|---:|---|---|
| 0–5 | `HIP_YAW`, `HIP_ROLL`, `HIP_PITCH`, `KNEE_PITCH`, `ANKLE_ROLL`, `ANKLE_PITCH` | joint angles, rad-scale (e.g. knee 0.19–2.51; units not documented) |
| 6–12 | `LEFT_SHOULDER_{PITCH,ROLL,YAW}`, `LEFT_ELBOW_{PITCH,YAW}`, `LEFT_WRIST_{PITCH,ROLL}` | joint angles |
| 13–19 | `RIGHT_SHOULDER_{PITCH,ROLL,YAW}`, `RIGHT_ELBOW_{PITCH,YAW}`, `RIGHT_WRIST_{PITCH,ROLL}` | joint angles |
| 20 | `NECK_PITCH` | 0.03–0.49 |
| 21 | left hand closure | 0 = open, 1 = closed |
| 22 | right hand closure | binary {0, 1} |
| 23 | base linear velocity command | [0, 1] |
| 24 | base angular velocity command | [−1, 1] |

Despite its name, `cartesian_position` is a joint-space vector plus hand flags and base velocity commands; there is
no end-effector pose.

## Stored h5 (`trajectory/…`)

| Field | Shape | Content |
|---|---|---|
| `observation/robot_state/cartesian_position` | [T, 25] | the state above; the only real array |
| `observation/robot_state/gripper_position`, `joint_position` | [T, 1] | all NaN (placeholders) |
| `action/cartesian_position`, `gripper_position`, `joint_position` | [T, 1] | all NaN (placeholders) |

## Typical values

| Signal | Units | Range | \|Δ\| per WM step |
|---|---|---|---|
| joints (0–20) | rad (assumed) | joint-dependent | p99 0.05–0.66 |
| hand closure (21–22) | flag | {0, 1} | Δ ∈ {−1, 0, +1} |
| base velocity commands (23–24) | apparently normalized | [0, 1] / [−1, 1] | up to ±1 (start / stop) |

## Notes

* **Base dims carry velocity changes, not motion.** Through the difference, a base driving at constant speed gives
  Δ = 0 and starting or stopping gives up to ±1. These are the two navigation dims of paper App. B.1.
* The NaN `action/*`, `gripper_position` and `joint_position` arrays are placeholders; the WM does not read them.
* **Inference** ([README](README.md#inference-what-worldmodelstep-does-per-id)): no preprocessor (zero-pad to 64).
  The rollout state update keeps only 7 slots as xyz + euler + gripper, so it is **not** consistent with this layout.
