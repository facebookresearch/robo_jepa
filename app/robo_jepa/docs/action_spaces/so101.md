# SO-101 / LeRobot (`so-101`, `so-101_joints`)

LeRobot SO-100/101 arm episodes. The joints are stored in radians, and the end-effector pose is normally
forward kinematics of the stored joints on the SO-101 URDF (`so101_new_calib.urdf`, link `gripper_frame_link`). Two
ids read the same episodes.

## Dataset

| Config entry | Embodiment (id) | Data (`s3_prefix`) | Raw → WM rate | Time per WM step | Cameras → view id | Weight |
|---|---|---|---|---|---|---|
| `Lerobot` | `so-101` (4) | `lerobot/single_arm_labeled` | 30 → 5 Hz | 0.2 s (6 frames) | `left` 0, `right*` 1, `wrist` 2, `top*` 5, `front*` 6; 2 at random | 0.0124 |
| `Lerobot_joints` | `so-101_joints` (25) | `lerobot/single_arm_labeled` | 30 → 5 Hz | 0.2 s (6 frames) | same | 0.0124 |

Eval-only: `Lerobot` in `data.eval` (`so-101`, `lerobot_eval_data_labeled/`).

## WM input

| Embodiment (id) | Source | State (dim) | Action per WM step (dim) |
|---|---|---|---|
| `so-101` (4) | state-delta, cartesian | EE pose (6) + gripper = 7 | Δxyz, relative rotation `R_{t+1}·R_tᵀ` as euler xyz, Δgripper = 7 |
| `so-101_joints` (25) | state-delta, joints | joints (5) + gripper = 6 | Δjoints, Δgripper = 6 |

`pose_dim: 6`, `gripper_dim: 1`, `joints_dim: 5`.

## Stored h5 (`trajectory/…`)

| Field | Shape | Content |
|---|---|---|
| `observation/robot_state/joint_position` | [T, 5] | shoulder_pan, shoulder_lift, elbow_flex, wrist_flex, wrist_roll (rad) |
| `observation/robot_state/cartesian_position` | [T, 6] | FK pose: xyz (m) + euler xyz (rad), `gripper_frame_link` in the base frame |
| `observation/robot_state/gripper_position` | [T, 1] | LeRobot gripper value × π/180 |
| `action/joint_position`, `cartesian_position`, `gripper_position` | same | the recorded teleoperation command (leader arm), same conventions; not used |

## Typical values

| Signal | Units | Range | \|Δ\| per WM step |
|---|---|---|---|
| joints | rad (LeRobot degrees × π/180) | — | — |
| roll, yaw | rad | cross ±π (harmless: the rotation difference goes through matrices) | — |
| gripper | raw × π/180 (not a [0, 1] closedness) | 0–1.745 for a 0–100 source scale | — |

## Notes

* **Gripper scale.** The gripper is the raw LeRobot value times π/180, not a [0, 1] closedness, so paper App. B.4's
  common [0, 1] scale does not hold here.
* **SO-100 episodes get an SO-101 pose**: the FK uses the SO-101 URDF for every repo.
* **Not every episode is FK-consistent.** Some episodes' stored pose does not match FK of their joints on this URDF
  (position off by up to 0.31 m), so they came from a different URDF or source.
* **Action leads state.** The recorded action matches the state about 4 raw frames (≈ 0.13 s) later: it is the
  teleoperation target the follower arm reaches, not a copy at the same step. Neither id uses it.
* **Inference** ([README](README.md#inference-what-worldmodelstep-does-per-id)): no preprocessor (zero-pad to 64).
  For `so-101` a 7-D planner action is the training layout and the rollout state update is consistent; for
  `so-101_joints` it is **not** (the joint state is integrated as xyz + euler + gripper).
